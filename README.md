# 👑 Mis 15 Años - Danna

Sitio web interactivo y mágico de invitación para la fiesta de 15 años de Danna.

## ✨ Características
- 💌 **Sobre animado de apertura** con música de vals y campanas mágicas.
- 📖 **Libro de cuentos interactivo** (Storybook) con navegación de páginas.
- ⏳ **Cuenta regresiva en vivo** hacia el 19 de Diciembre de 2026.
- 📍 **Ubicación GPS interactiva**: Quinta Marbella con enlace a Google Maps y Waze.
- 👗 **Código de vestimenta (Dress Code)**: Elegante / Formal (Dorado, Rosa Pastel, Borgoña).
- 🎁 **Mesa de regalos y transferencias bancarias** con botón de copiado rápido de Alias/CBU.
- ✉️ **Confirmación de asistencia (RSVP)** directa a WhatsApp.
- ⚙️ **Panel de control administrativo** con clave secreta (`90415`) para editar datos en vivo.

## 🚀 Tecnologías
- React 18 + TypeScript + Vite
- Tailwind CSS
- Lucide React Icons
- Web Audio API (Música de vals y efectos mágicos)
